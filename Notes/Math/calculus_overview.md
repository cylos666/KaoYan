# 考研高数·题型分类总结

> 📌 **本章内容**：高等数学各章节题型与核心方法总览，帮你建立完整的知识框架。

## 一、极限与连续

| 题型 | 核心方法 |
|:---|:---|
| **$0/0$ 型极限** | 等价无穷小代换、洛必达、泰勒展开 |
| **$\infty/\infty$ 型极限** | 洛必达、抓大头、分子分母同除最高次 |
| **$1^\infty$ 型极限** | 重要极限 $\lim(1+x)^{1/x}=e$，取对数 |
| **$\infty-\infty$ 型极限** | 通分、有理化、提公因式 |
| **$0\cdot\infty$ 型极限** | 化为 $0/0$ 或 $\infty/\infty$ |
| **无穷小比阶** | 泰勒展开到同阶 |
| **数列极限** | 单调有界准则、夹逼准则、定积分定义 |
| **无穷大 × 非零周期函数** | 无界但不为无穷大 |
| **复合函数反推内层极限** | 外层单调+内层有界→内层极限存在 |
| **连续与间断点** | 左右极限判定间断类型 |

> 📎 **关联章节**：[极限例题精讲](calculus_limit.md) | [连续与间断点](calculus_continuous.md) | [泰勒展开与等价无穷小](calculus_taylor.md) | [洛必达法则失效](calculus_lhopital.md)

## 二、一元函数微分学

| 题型 | 核心方法 |
|:---|:---|
| **导数定义求极限** | $f'(x_0)=\lim_{h\to0}\frac{f(x_0+h)-f(x_0)}{h}$ |
| **隐函数求导** | 两边同时对 $x$ 求导，解出 $y'$ |
| **参数方程求导** | $\frac{dy}{dx}=\frac{y'(t)}{x'(t)}$ |
| **高阶导数** | 莱布尼茨公式、数学归纳法 |
| **中值定理证明** | 罗尔定理、拉格朗日、柯西、泰勒 |
| **单调性与极值** | 一阶导数判单调，二阶导数判极值 |
| **凹凸性与拐点** | 二阶导数符号判断 |
| **渐近线** | 水平/垂直/斜渐近线 |
| **方程根的个数** | 零点定理 + 单调性 |

| **定积分计算** | 牛顿-莱布尼茨、对称区间奇偶性 |

## 📖 考研数学·核心定义梳理

> 定义是解题的出发点。以下梳理考研数学中**最常考、最易混淆**的核心定义及其关系。

### 极限相关定义

| 概念 | 定义 | 关键点 |
|:---|:---|:---|
| **数列极限 ε-N** | $\forall\varepsilon>0,\exists N,n\ge N\Rightarrow\|x_n-a\|<\varepsilon$ | $\varepsilon$ 可任意小，$N$ 依赖 $\varepsilon$ |
| **函数极限 ε-δ** | $\forall\varepsilon>0,\exists\delta>0,0<\|x-x_0\|<\delta\Rightarrow\|f(x)-A\|<\varepsilon$ | **去心**邻域，$f(x_0)$ 可无定义 |
| **无穷小** | $\lim f(x)=0$ | 极限为 0 的函数 |
| **无穷大** | $\forall M>0,\exists\delta>0,\|f(x)\|>M$ | 最终恒大于任意正数 |
| **无界** | $\forall M>0,\exists x,\|f(x)\|>M$ | 存在大于 $M$ 的点，但不要求"所有" |

> ⚠️ **无穷大 ⇒ 无界，但无界 ⇏ 无穷大**（如 $\frac{1}{x}\sin\frac{1}{x}\to 0$）

### 连续相关定义

| 概念 | 定义 |
|:---|:---|
| **连续** | $\lim\limits_{x\to x_0}f(x)=f(x_0)$ |
| **左连续** | $\lim\limits_{x\to x_0^-}f(x)=f(x_0)$ |
| **第一类间断点** | 左右极限均存在（可去：相等；跳跃：不等） |
| **第二类间断点** | 至少一侧极限不存在（无穷/振荡） |

### 导数相关定义

| 概念 | 定义 |
|:---|:---|
| **导数** | $f'(x_0)=\lim\limits_{h\to0}\frac{f(x_0+h)-f(x_0)}{h}$ |
| **左导数** | $f'_-(x_0)=\lim\limits_{h\to0^-}\frac{f(x_0+h)-f(x_0)}{h}$ |
| **可导** | 左右导数存在且相等 |
| **可微** | $\Delta y = A\Delta x + o(\Delta x)$，其中 $A=f'(x_0)$ |

> 📌 **关系链**：可导 ⇔ 可微 ⇒ 连续 ⇒ 极限存在（箭头不可逆）

### 积分相关定义

| 概念 | 定义 |
|:---|:---|
| **定积分** | $\int_a^b f(x)dx = \lim\limits_{\lambda\to0}\sum f(\xi_i)\Delta x_i$（Riemann 和极限） |
| **原函数** | $F'(x)=f(x)$，则 $F$ 是 $f$ 的原函数 |
| **变限积分** | $\Phi(x)=\int_a^x f(t)dt$，若 $f$ 连续则 $\Phi'(x)=f(x)$ |

> ⚠️ **可积 ⇏ 有原函数**，**有原函数 ⇏ 可积**（两个独立概念！）
