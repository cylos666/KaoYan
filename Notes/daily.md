  一道判断函数在可疑点是否连续的题目时，你按以下逻辑步骤思考并输出：

1. 明确最终目标：判断函数在 x = x0 处是否连续。

2. 写出连续的定义式：
   lim_{x -> x0} f(x) = f(x0)

3. 拆解定义式，得到两个必须知道的子目标：
   - 子目标 A：函数值 f(x0)
   - 子目标 B：极限值 lim_{x -> x0} f(x)

4. 判断是否需要进一步拆解：
   - 若 f(x) 是分段函数，或题目含参极限（如 n -> ∞），则 B 需要拆解为：
     * 左极限 lim_{x -> x0^-} f(x)
     * 右极限 lim_{x -> x0^+} f(x)
   - 若左右极限都存在且相等，则 B 存在；否则不存在。

5. 根据拆解结果，依次计算：
   - 先求出 f(x) 的完整表达式（可能通过分情况讨论极限）
   - 再代入 x0 得 f(x0)
   - 再计算左右极限

6. 最后比较：
   - 若 lim_{x -> x0} f(x) 存在 且 = f(x0) → 连续
   - 否则 → 不连续
