## 常用模板

### 大作文

#### 开头段

```
As is vividly depicted in the cartoon, ...
The picture/symbol/statistics shows/reveals that ...
```

#### 中间段

```
The primary reason for this phenomenon is that ...
Furthermore, ...
According to a recent survey, ...
```

#### 结尾段

```
From my perspective, effective measures should be taken to ...
Only in this way can we ...
```

### 小作文

#### 建议信

```
Dear XX,

I am writing to express my views concerning ...

I hope you will find these proposals useful.

Yours sincerely,
Li Ming
```

#### 感谢信

```
Dear XX,

I would like to express my sincere gratitude for ...

I am truly grateful for your help.

Yours faithfully,
Li Ming
```
